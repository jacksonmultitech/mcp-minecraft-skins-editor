MCP del Editor de Skins de Minecraft

Conecta a Claude con el Editor de Skins para que cree y edite tu skin en vivo mientras tú miras. Cada cambio de Claude se puede deshacer con Ctrl+Z.

1. Agrega el conector en Claude

Usa esta URL como conector personalizado (servidor MCP remoto, sin autenticación):

https://…/mcp
  • claude.ai o Claude Desktop: Configuración → Conectores → Agregar conector personalizado → pega la URL.
  • Claude Code: claude mcp add --transport http skins https://…/mcp

Los nombres de los menús pueden variar según la versión de Claude.

2. Conecta tu editor

  1. Abre el Editor de Skins.
  2. Pulsa Conectar con Claude y luego Conectar. Aparece un código como K7QM-X2PD-9RTA.
  3. Dile a Claude algo como: "Usa el editor de skins con el código K7QM-X2PD-9RTA y hazme un caballero con armadura azul".

Herramientas disponibles

HerramientaQué hace
get_uv_layoutMapa de la textura 64×64: dónde está cada parte y cara.
color_harmony · tonal_scaleArmonías de color y rampas de sombreado (normal o pixel art).
get_editor_stateModelo, colores usados y avisos de compatibilidad.
get_skin_imageImagen del personaje en 3D o de la textura plana, para que Claude revise su trabajo.
fill_face · draw_face_pattern · paint_pixelsPintar: caras completas, dibujos tipo arte ASCII (ojos, boca…) y píxeles sueltos.
add_noise · mirror_side · clear_layerTextura, simetría y limpieza de capas.
new_skin · set_modelEmpezar de cero o desde plantilla; brazos clásicos (4 px) o delgados (3 px).
undo · redo · download_skinDeshacer, rehacer y descargar el PNG.

Privacidad y seguridad

  • Solo quien conozca el código de tu sesión puede enviar órdenes a tu editor. El código vence a las 3 horas, y el editor se desconecta solo tras 30 minutos sin actividad.
  • El servidor guarda temporalmente las órdenes pendientes (segundos) y no guarda tus skins.
  • El puente del editor solo acepta peticiones desde la página oficial del editor.
